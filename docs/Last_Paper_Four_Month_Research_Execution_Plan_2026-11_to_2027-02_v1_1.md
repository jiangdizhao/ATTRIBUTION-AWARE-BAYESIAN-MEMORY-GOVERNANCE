## 01｜研究决定、路线关系与权限

| 路线 | 当前角色 | 研究对象与许可边界 |
|---|---|---|
| A：属性反馈持久迁移 | 优先，继续可行性验证 | 固定词表下的属性识别与纠正传播；不因本次重审终止；D6 运行仍依具体契约授权 |
| ABMG：归因式记忆治理 | 独立、条件性备选 | 丰富缺陷证据如何选择性更新和复用修正状态；先论证、后授权，不默认替换 A |
| C：一步反馈价值 | 有限候补 | 固定有效学习算子后研究取证价值；不以改查询掩盖无效更新 |
| B：动态规则/Schema 修订 | 本期暂缓 | 不同时学习属性词表、验收规则、Schema 创建/拆分；不自动成为救援路线 |

A 与 ABMG 可以共享冻结特征、反馈账本、区域证据与评价工具，但科学比较分别定义。A 主要检验属性知识向未来实例的迁移；ABMG 主要检验把证据写入何处、以何种强度读取/修正，以及治理是否改善未来效用。共享实现不能替代独立归因。

历史 Scheme B 指 EG-FAMAR；本计划 B 指动态规则修订；两者不可混用。ABMG 的加入不复活旧 Scheme B 全部 G0–G4。

研究者当前批准的是战略修订和文档提交。既有运行契约内的许可保持原范围；未授权 Target、Probe、Mint/PCB、Calibration Stage、额外付费及新数据访问继续隔离。A 的研究连续性与一次具体运行是否获准，是两个不同状态。

## 02｜为什么重审 ABMG，而不是抹掉负结果

原始 ABMG 允许机器归因、人类归因或二者结合；确认缺陷更新纠错/归因状态，不自动扩张正常性。它不以“仅凭 binary 自动恢复全部语义因素”为必要条件。[P6 §8]

| 已有证据 | 本版保留的结论 | 禁止的过度外推 |
|---|---|---|
| β-VAE 重建与测试的 32-D sidecar 未达标 | 停止依赖这些配置；保留 raw DINO 对照 | 所有可寻址表示或属性学习均无效 |
| Five-Branch 正确写址优于广播/错址 | 已知来源条件下写入目的地重要 | 已证明自主语义发现、正常记忆安全或多异常组合能力 |
| E3 NIG 改善边际区间校准 | 不确定性建模有有限经验依据 | 已证明未知缺陷安全、查询节约或治理必要性 |
| E4B 增益小且未连接最终二元评分 | 原来源增强算子未过门槛 | 丰富 defect feedback 不能改善 signed correction |
| H1 结构编辑候选遇到不可识别/强基线挑战 | 停止那个具体候选的强主张 | 新增合法属性/区域信息后仍必然不可行 |

因此，恢复的是可证伪的核心问题，不是宣布旧方案已成功。32-D 与 1024-D 的压缩混杂、任务端点差异、监督范围差异都须保留。[P1、P3、P7]

研究者报告前作近期证明 signed correction 对动态正常记忆有额外贡献。本版将其记为 USER_REPORTED，作为重审动机；本次没有读取该轮精确配置、原始结果与代码，不新增数值或宣称已独立复核。整库增益、正向 defect 分量增益及属性寻址增量须分别验证。[P8]

D4-Lite、D4B、Real-IAD D5R-P2 V2 的人工试标已完成。最新 V2 为 58 次呈现、48 个唯一图像、24 个 sample-key、6 产品各 4 组；盲重复 8/10 一致。首次标签 Present 25、Absent assessable 19、Unobservable/uncertain 4。以上来自 D6 交接，本次未重新计算 CSV。[P5]

## 04｜共同科学问题与监督对象

中心问题：一份稀疏、经确认的视觉证据，应改变哪些持久状态，并在什么区域、属性与上下文中影响未来判断，才能获得收益而不把错误扩散到不适用实例？

| 对象 | 准确定义 | 不得等同于 |
|---|---|---|
| 属性 | 可观察、可跨实例描述的性质 | 数据集 defect type、物理根因 |
| 空间证据 | 属性或异常在图像中的位置/支持范围 | 所有 top-K patch 都被人工确认 |
| 上下文 | 材料、部位、邻域关系、拍摄条件等可见信息 | 隐藏标签或直接答案 |
| 地址 | 可被独立读取/更新的状态目的地 | 必须是 DINO 某个原始坐标 |
| 验收规则 | 某属性在某条件下是否应上报 | 属性是否存在本身 |
| 未来收益 | 未参与更新的后续独立实例改善 | 当前人工纠正后的正确答案 |

允许反馈包括 binary、defect type、point/box/scribble/mask、属性存在/不存在/不确定、属性—区域绑定、合法成对关系。是否提供与以何成本提供须逐事件记录，不把丰富反馈限制为原来两种固定套餐，也不把所有字段默认免费开放。

固定 backbone 不等于所有下游参数永远冻结。A 可更新轻量属性头；ABMG 可仅更新外部状态。若候选更新下游投影，必须声明该变化、计入训练成本，并同步提供给公平基线；不得声称全系统无梯度。

## 05｜丰富反馈的权限与成本契约

| 已获得的反馈 | 可支持的更新 | 不能自动推断 |
|---|---|---|
| 图像正常 | 可信正常证据候选、正常统计、必要的负向纠错 | 每个 patch 都新颖；所有属性都 absent |
| 图像缺陷 | 图像/实例包证据、待定位纠错候选 | top-K 都是缺陷；缺陷类别或位置已知 |
| defect type | 来源标签/类型记忆 | 具体区域或可迁移属性身份 |
| 联合异常 mask | 被标为异常的空间范围 | 每块异常属于哪个属性 |
| 属性描述 | 被明确标注属性的判断 | 未提及属性不存在、整图正常 |
| 属性＋对应区域 | 属性条件的局部修正与统计 | 区域内其他共存异常也被排除 |
| 上下文/关系说明 | 所说明范围内的适用条件 | 未给出的工艺规则或未来标签 |

每个事件保留 annotation_mask 与 applicability_mask，区分 absent、unknown、unobservable、not applicable。弱位置与精细 mask 不互相冒充；属性否定不是正常性标签。

成本分别核算发现图像、binary、type、属性、空间绑定、额外关系与复核；同一事件共享已有证据不重复收费，追加信息按增量收费。真实时长与假设成本分表，旧试标时长不可靠时保留状态，之后统一采用预注册的假设成本敏感性，不称实测节约。

两类比较分别进行：同事件/同字段检验机制；同总人时检验效率。不能让新方法独占更丰富监督后把收益归于更新规则。

## 06｜多异常：属性—区域—上下文绑定

一图可同时有擦伤、污染物或其他异常；同一区域也可能重叠。属性存在使用可共现的多标签状态，不用跨属性 softmax 强制互斥。按地址分配一次事件的写入质量，与多个属性是否存在，是不同变量。

最小证据单元为“事件 e、区域 p、属性 k、可见上下文 c、确认值、权限与可靠性”。e 是反馈事件，p 可为 patch/区域，k 是固定词表中的属性，c 为合法上下文。无绑定时保留 uncertain bag，不把整图表示当作某属性的充分位置证据。

**A1 的作用域修订：** Δz_k(x,p) = clip(Σ_e r_k(e,x,p,c)·d_e,k, −D_k, D_k)。

x 为当前图像；z_k 是属性 k 的识别输出或明确定义的 logit；d_e,k 是历史事件对该属性的修正量；r_k∈[0,1] 为该事件对当前区域的适用权重；D_k 为源侧固定的总修正幅度界。只累加有合法 k 反馈的事件；和式不跨属性竞争。概率输出须另作合法映射，不能把无界和直接称为概率。

对擦伤的纠正可以读取污染物周围上下文，但不能因此把污染物写成 absent。“擦伤允许”不能覆盖“污染物违规”。当前单属性 D6 继续，不因暂时没有多异常样本被终止；多异常先纳入数据模式和边界，随后用有授权的有限独立组检验。未检验时限制组合性主张。

## 07｜上下文、固定规则与开放集保护

原则是“读得足够广，写得有依据”。同一细线是否为划伤，可能依赖材质、规则纹理、部件边界与正常参考。局部更新不等于裁掉背景；给全部方法相同的局部、邻域、产品级上下文可见性。

产品 ID 可用于共享的验收规则选择，但不能作为隐藏属性答案。属性识别要检验它是否依赖可迁移的材料/结构关系；未知产品必须有共享回退与不确定处理。外观远指材料、颜色、形状或特征距离差异，不指图像太远、模糊而不可观察。

基础异常分数 s₀(x) 保留。属性状态 z=gθ(h,c)，其中 h=fφ(x) 为冻结特征，θ 为可更新状态，φ 在线不变。固定任务层 qψ(z,c) 与融合 F 形成 s(x)=F(s₀(x),qψ(z,c))；ψ 与 F 在比较前源侧冻结。

“擦伤可接受”只解除该属性在相应区域/上下文的上报理由；不能整图一票否决污染物或未解释的异常。负向抑制必须限定其解释范围、幅度及冲突处理。基础通路保留不是未知缺陷安全定理，最终仍报告词表外缺陷表现。

先把属性学习作为可行性对象，固定任务接口作为下游条件。真属性读出不能利用任务时，先检查规则/融合是否失配，不立刻否定整个 A；若只建立属性迁移，就只报告该层，不冒称已经改善检测。

## 08｜A1：区域与上下文条件化的纠正传播

**身份：候选，原 HOLD 记录保留；本版完善定义，不宣布已运行或自动解除候选运行许可。**

A1 保存被确认属性的局部纠正，估计它对未来独立实例的适用性。由局部描述、邻域结构、合法上下文、属性身份与可靠性构成 r_k 的输入，按第 06 节有界组合。禁止读取当前隐藏属性、未来标签或 evaluator 的“同属性分组”。

与原版相比，事件拆为可共存属性证据，而不是整图纠正包；属性对应区域独立；冲突与过度重复累计有固定规则；相同区域可容纳多个属性。支持单属性最小实施，不以一次构建完整多属性系统为起点。

| 内容 | 具体要求 |
|---|---|
| 必须比较 | CB2M 匹配版、同局部/上下文增强 CB2M、区域近邻、可学习相似度、普通在线属性头＋回放 |
| 监督匹配 | 用于训练适用性的源侧事件—未来配对，也提供给合理增强对手 |
| 可辨预测 | 在可观察的远外观同属性组扩大正确复用，在近外观异属性组减少误传播；完整测试同时保留 |
| 保持检查 | 纠正一个属性后其他已核验属性、同图并存异常与历史正确样本的变化 |
| 降级边界 | 若仅换相似度即可复现收益，贡献按相似度/条件检索表述，不包装成通用记忆理论 |

首次候选包上限沿用 5 工作日、30 GPU 小时、最多 3 个源侧配置；起步 2 个 seed、2 个开发分组。统计不足时不冒称确认；没有具体运行 GO 不执行。

## 09｜A2：对比证据驱动的共享属性更新

**身份：SCREEN；筛查机会不是已验证有效，也不是本轮自动开始新算法。**

A2 更新共享的轻量属性识别器，而非仅重用残差。合法人类反馈只监督被标注属性；源侧或付费关系对连接跨产品同属性与近外观异属性实例。未标注不作 0，混合异常图像不把全部区域赋为同一属性。

候选目标为 L = L_attr + λ_pair L_pair + λ_keep L_keep。L_attr 是已标注属性损失；L_pair 是合法关系约束；L_keep 仅使用合法历史证据保持知识；两个 λ 为源侧选定的非负权重。这个常规组合不是创新证明，具体贡献须落实到证据分配、更新范围或实际性能—成本性质。

上下文和区域特征先与基线共享。若更新共享投影会影响所有属性，须显式统计跨属性干扰；不能仅靠损失掩码宣称其他属性不变。必要的独立属性头、局部状态或回放属于候选设计，不预设必须采用哪种。

比较同监督 logistic/小 MLP＋回放、同关系对对比学习、递归岭回归/CONCIL-style、区域原型、CB2M；编辑/去偏主张涉及 CBDebug 或 Editable CBM 时纳入最接近对手。[R2、R4–R6]

小幅但稳定的收益可以保留；仅来自更多关系标签、更强区域输入或更大容量则是监督/资源效应。先确认共享识别可行，再判断是否存在值得做的新机制；常规损失形式不构成提前终止 A 的理由。

资源上限同 A1。允许梯度更新轻量头，backbone 不变；比较不同维度时保留 raw 特征和同维度对照。

## 10｜A3：共享—局部状态与干扰管理

**身份：当前优先作为强基线和组织原则；只有独立新机制成立时才升级候选。**

w_k,c = w_k,shared + v_k,c。w_k,c 是上下文 c 的属性 k 参数；w_k,shared 是共享参数；v_k,c 是局部偏移。加和可改变特征权重，不只是输出平移；但共享/局部分解并不唯一，因此形式本身不证明学到了通用知识与例外。

以源侧固定的局部先验收缩、中心化约束或共享锚定消除不必要自由度；各对照采用相同基础约束。未知上下文回退到共享项并保留不确定性。仅按产品 ID 分组时，不声称学到可迁移语义。

候选更新原则：单次上下文特定反馈先作用于有明确适用范围的状态；只有合法跨上下文一致证据才更有理由改变共享部分。所谓一致需要预先定义证据条件和最低支持，不能事后按有利结果选择，也不能以罕见语义词自动共享。

| 干扰来源 | 必须控制/记录 |
|---|---|
| 共享参数更新 | 对未标注属性与旧上下文的预测变化 |
| 共享路由/归一化 | 即使属性头不变，也可能改变输入与行为 |
| 共享容量/淘汰 | 写入擦伤不能无记录挤掉污染物证据 |
| 属性间真实相关性 | 有证据的关联变化可以允许；不追求不合理的绝对独立 |

条件性保证：只有其他属性所依赖的输入、参数、读取规则与记忆都不变，才能保证其读出不变。实际系统另报行为干扰。比较全共享、全局部、固定收缩、上下文统一头与条件原型，不预设 Bayesian 分层必胜。

## 11｜A 的持续验证路径：不因本版重启或终止

D6 延续已有试标、权限记录和待办，不重新开展第三/第四轮泛化的“人能否判断 abrasion”试点。本版新增区域/上下文/多异常要求，先进入契约与失效清单，不能让当前单属性可行性无限等待完整系统。

| 包 | 核心问题与交付 | 决策含义 |

| A-F0 / D6-P0 | 明确合法 D-fit/D-dev/未来组、反馈字段、成本、冻结读出与基线接口 | 准备契约；不是算法运行 |
| A-F1 / D6-P1–P2 | No-update、在线属性头、递归岭、区域原型、CB2M；区分反馈质量与任务读出 headroom | 有效失败画像；没有足够独立组则 INCONCLUSIVE |

## 12｜ABMG 备选：问题、定位与可检验假设

备选全称：Attribution-Aware Bayesian Memory Governance。工作解释：在冻结视觉底座上，以丰富反馈绑定区域、属性和上下文，选择性更新外部修正状态；单独判断 Bayesian 不确定性是否改善写入与复用决策。

**与 A 的差别。** A 的中心对象是可迁移属性识别；ABMG 的中心对象是证据到持久修正状态的信用分配和治理。可共享属性接口，不把 A 的属性 AP 当作 ABMG 的纠错增益，也不把正常覆盖收益等同于属性学习。

| 假设 | 要验证的机制增量 | 不能拿什么替代 |
|---|---|---|
| H-M1 选择性信用 | 相同缺陷反馈下，区域/属性/上下文寻址比普通 signed correction 更好地改善未来相关错误，并限制无关传播 | 正确地址比随机地址好；单纯重演 Five-Branch |
| H-M2 可部署地址 | 合法历史或当前已购买丰富反馈足以提出有用地址，错误/弃权可管理 | 当前隐藏 mask、来源真值或未来标签 |
| H-M3 Bayesian 增量 | 同地址、同证据、同动作下，不确定性改变决策并带来效用/成本收益 | 仅边际区间覆盖改善 |
| H-M4 经验摊销 | 同可靠性和可比重复情境下，修正复用减少人工依赖 | 预算耗尽、价格控制或过度自信造成少问 |

H-M1/H-M2 成立而 H-M3 不成立时，保留 attribution-aware memory correction，撤回 Bayesian 必要性；不因标题中有 Bayesian 强行保留模块。旧 β-VAE 与全坐标 NIG 不是启动前提。

## 13｜ABMG 最小状态、地址与读写路径

保持基础正常 NN 与已核验 signed correction 基线。最小可变对象为证据账本 E、地址条件修正状态 C、可选治理状态 B；正常参考 M_N 的轨迹在首个机制比较中共享固定，避免同时改变正常覆盖与纠错。

s_t(x,p) = s_N(h_t,p;M_N) + δ_t(x,p)。h_t,p 是 t 时刻图像 x 在区域 p 的冻结特征；s_N 是正常参考分数；δ_t 是有界残差；较高表示更异常。这个分解是实现接口，不是创新定理。

地址建议为 a=(k,u)：k 表示被确认或候选属性，u 表示上下文/适用范围分区；每个地址可有多个有来源的局部锚点，不强制一个质心代表多模态。空间位置 p 是证据定位，不等于语义地址。属性 k 可以对应一组读出参数或外部统计，不必对应固定 DINO 坐标。

α_e,p,a∈[0,1] 表示事件 e 的区域 p 对地址 a 的写入质量；未授权属性权重为零。一个事件可向多个已确认属性写入；每个属性的事件总权重有上限，避免把 784 个相关 patch 算成 784 次独立人工观察。复制或拆分地址不得无限增加证据质量。

当前人类明确给出属性时，可直接使用该语义身份；学习仍需处理空间绑定、上下文范围和未来适用性。仅凭历史路由时，保留 unknown/new/abstain，不强制新模式落入某个旧来源。

## 14｜ABMG 选择性修正与可部署地址

**处理次序。** 先记录原始预测；揭示已购买字段；构造区域—属性证据；提出地址与更新；比较只读影子状态；批准后产生写入收据；仅作用于后续样本。单次缺陷二元标签不自动产生可信正向 patch 原型。

一个透明的候选读出为 δ(x,p)=clip(Σ_i K_i(h_p,c)β_i,−D,D)。i 为已授权锚点，β_i 为带符号修正系数，K_i 为绝对距离衰减并受属性/上下文约束的匹配权重，D 为源侧固定幅度界。K_i 远离全部锚点时趋零；不能用“归一化后的 Gaussian 权重之和为 1”冒充绝对局部性。

此形式仅作基线/候选说明。正式试验必须锁定所选 signed correction 版本；新方法与非寻址对照共享候选 patch、核带宽、容量、修正目标和阈值，不能把核修复冒称地址贡献。

正向 defect evidence、负向 normal correction 与属性存在值分别存储。污染物确认不能被擦伤允许规则抹掉；属性 absent 也不自动成为负向正常纠错。修正当前分数的收益不能记作未来学习。

Five-Branch 支持写址重要；memory-addressability 表明历史记忆可预测来源，但预测准确不等于可安全写入，macro-F1 不是单次写入概率。[P7] 合法可部署地址可用属性监督、区域原型、上下文匹配；简单路由为强基线。错址风险取决于错误写入的后续代价，因此设置弃权/暂存并记录被拒绝的有用更新，避免“少写就显得安全”。

## 15｜ABMG Bayesian 治理：候选而非必要组件

选择一个具有明确统计含义的局部更新模型，而不是把正常特征 NIG 当作所有风险的替代。可选起点是低维修正回归：d_e=φ_eᵀβ_a+ε_e，ε_e∼N(0,σ²)。d_e 是由合法反馈与已固定评分规则定义的修正目标；φ_e 是固定的局部证据向量；β_a 是地址 a 的修正参数；σ² 为事前或源侧确定的噪声尺度。

若 β_a∼N(m_a,V_a)，一次加权更新可写为 V′_a⁻¹=V_a⁻¹+α_e φ_eφ_eᵀ/σ²；m′_a=V′_a[V_a⁻¹m_a+α_e φ_e d_e/σ²]。m_a、V_a 是参数均值与协方差；α_e 是第 13 节合法证据质量。重复 patch 不是独立样本，先按事件聚合或限制有效质量。

这是普通共轭/加权回归候选，不是新定理。α 为经验软责任时属于加权似然近似；模型错设、相关样本与选择偏差可能破坏校准，不宣称精确真实后验。若仅有 binary/type、没有可定义 d_e 的区域证据，保留弱实例包，或采用合法标签似然；不能凭空创建连续真值修正目标。

治理动作限定为 approve、defer、quarantine、reject 或请求已允许的额外证据。用后验不确定性评估有限历史证据上的修正效果与干扰，不以未知缺陷“零观测风险”作全局安全保证。

匹配确定性对照：相同 φ、目标、先验均值/正则强度和质量权重的 ridge/收缩估计，加同样的历史回放检查；另比较简单计数/阈值门控。若 posterior mean 与 ridge 等价，不能把均值收益归于 Bayesian。只有不确定性改变合法动作并改善效用，才支持 H-M3。

## 16｜ABMG 三个紧凑验证包与最小对照

以下均为备选计划，NOT_RUN；需在不挤占 A 当前可行性验证的前提下明确授权。避免碎片化：地址、Bayesian 与复用各对应一个紧凑比较包。

| 包 | 固定条件与核心分支 | 主要判定 |
|---|---|---|
| M0 证据继承与基线 | 核对最新 signed correction 的代码/配置/结果；恢复同信息非寻址纠错；共享正常记忆轨迹 | 明确整库、正向 defect 分量与地址增量；未核验不进入科学比较 |
| M1 信用与作用域 | 相同 rich feedback、patch、容量、修正核和阈值；普通 signed bank、简单区域/上下文原型、拟议选择性写读；加入质量匹配广播/错址、只读；Oracle 仅诊断 | 是否超越最强简单同信息对手，而不只是超过故意错误写址 |
| M2 治理与未来复用 | 固定 M1 合法地址；确定性治理 vs posterior-aware；在同包中观察未来组、混合异常与有限成本/风险曲线 | 不确定性有无独立动作/收益；人工依赖是否下降、错误传播是否受控 |

必要时在 M1 内做“写址改变/读出固定”和“存储固定/读出改变”的成对消融，区分写入与检索贡献；不把每项诊断扩成独立项目。固定查询用于机制归因；人工需求评价另用相同冻结的需求驱动策略，不同时开发 C。

强对照包括同信息 signed correction、signed kNN/区域原型、共享或上下文条件轻量头、同统计 ridge/确定性治理、CB2M 适配版（若主张涉及属性干预复用）。原版与改造版分开；普通 supervised class memory 必须有公平机会。

**进入条件。** A 仍优先完成当前可行性判断。ABMG 可先做有界文档/理论核对；实证开启需独立签署：具体未解决失败、相对 signed correction 的单一改变、合法反馈与未来组、强对照、资源来源。无需等待 A 被判失败，也不能因它是备选就自动停 A。

## 19｜分组、曝光与无泄漏的共同协议

D-fit 用于公开声明的初态/源侧训练；D-dev 用于开发与选择，记录全部尝试；D-conf 按物件/产品预先封存，冻结后才打开；D-ext 仅作获准外域。旧 Real-IAD 五折只在继续采用原协议时完整继承，不能把已曝光产品换个 fold 就称未见。

D6 交接记录已曝光 54 张 CONVAD 图像与原 120 张 Real-IAD 图像；不得纳入新研究未曝光 D-conf。sample-key 的独立性须核对，不能用同组另一个视角评价“未来独立物件”。[P5]

A/ABMG 机制回放共享事件、字段、时间戳、初态、support、特征与合理容量。先预测→查询→揭示付费信息→更新。未来评价标签不进入 learner；同产品适应与跨产品迁移分开。控制器比较允许 queried IDs 与标签构成改变，只匹配权限、初态与成本，不能固定策略本应改变的结果。

| 最小测试 | 应满足的不变量 |
|---|---|
| 随机替换未查询真值 | 在线预测与状态不变 |
| read-only 与 no-update | 无持久写入时，未来状态/输出一致 |
| checkpoint 恢复 | 同输入/反馈下在事前容差内复现 |
| 更新一个属性 | 未授权状态无变动；共享依赖变化另报 |
| 事件重复/patch 重复 | 不放大人工监督次数与质量 |
| 多属性冲突 | unknown 不作 negative；允许属性不覆盖独立违规证据 |

## 20｜评价一：未来效用、保持与证据分解

主任务候选仍为 TBA：BA=1−(FPR+FNR)/2；TBA=Σ_j ω_j MacroBA_future(b_j)。FPR/FNR 分别为误报/漏检率；b_j 是累计人工成本节点；ω_j 是归一化梯形积分权重。先按产品等权，再沿预算积分；当前人工纠正不计未来学习收益。

默认节点为总预算的 0、10%、25%、50%、100%；小诊断可用 16/32 共享反馈事件但不保证统计充分。基础 detector 与融合输出并报，FPR@固定 TPR 仅作离线诊断，不冒称部署可用阈值。

| 维度 | 核心报告 |
|---|---|
| 属性迁移 | 已核验且适用的属性 AP/BA；同产品、跨产品、可观察的远外观同属性分层 |
| 多异常保持 | 被纠正属性与并存未纠正属性分别报告；同区域重叠和不同区域分开 |
| 行为干扰 | 原本正确的独立样本变错率、最差产品、无关属性退化；不把本来错误算新伤害 |
| 状态局部性 | 参数/充分统计/地址/容量变化；与行为局部性分表 |
| 检测与安全 | TBA、AUROC/AP、FPR/FNR、已知/词表外/反馈未覆盖缺陷；无足够样本不作安全结论 |
| 资源 | 标注时间/事件、源侧额外监督、内存字节/原型数、更新与推理延迟 |

对 A 强调属性状态改变是否解释未来任务收益；对 ABMG 强调地址/治理是否在相同 signed correction 下提供增量。反馈更多、核更局部、阈值变化和容量增大都是必须单列的替代解释。

## 21｜评价二：越学习，是否越少依赖人工

新增共同目标：在可比的重复情境与同等可靠性下，经验积累降低重新求助的需求。不是要求全流查询率单调下降；新异常、矛盾或分布变化时合理查询可以回升。

旧 v22 的目标率价格控制为 c_next=clip[c+η(ρ_hat−ρ_target)]。c 是查询价格，η 为步长，ρ_hat 为近期率，ρ_target 为目标率；低于目标会降价。因此启用时约 3% 的稳定率不能直接否定知识增长；最新前作是否仍用它要另核验。[P4]

人工需求评价使用共享冻结的风险/价值规则或固定价格，另加明确预算上限，不能用追踪 3% 的机制强迫花满。3% 若保留，须注明是上限而非使用配额；有限流/滚动窗口的预算语义写入契约。不默认恢复强制 warm-up query；审计查询如需保留，应单列、计费并相同设置。

| 指标 | 解释与限制 |
|---|---|
| 重复情境查询曲线 Q_repeat(n) | 获得 n 次合法相关经验后，对独立重复情境的实际查询比例；按可见规则分组，不能用隐藏标签控制 |
| 等可靠性人工成本 | 在预注册风险/效用标准满足时累计人时；须独立评价，不能以主观置信下降代替 |
| 重新求助成本 | 已学情境间隔/回访后的新增标签与费用；排除同物件近重复 |
| 校准与漏检 | 查询减少同时是否过度自信、隐藏错误增多、预算耗尽 |

固定反馈回放只能检验学习机制，不能直接声称观察到自适应少问。可冻结状态做需求诊断，但标为诊断；真正节约需要闭环计费评价。所有审计/复核成本进入总额，按反馈丰富度报告，不能只比较次数。

## 22｜贡献标准与统计：小收益可以重要，但不能换口径

δ_task=0.02 的 TBA 改善与 ε_FN=0.01 的未知缺陷 FNR 增量，是 v1.0 默认规划值，不是科学价值的普遍门槛。本版保留它们作为待冻结候选值，同时允许在看新候选结果前，基于 baseline-only 方差、任务代价与资源目标选择一种主贡献路径。

## 26｜停止、补足与范围降级：五种层级分开

| 层级/状态 | 触发与处理 |
|---|---|
| 工程 INVALID/BLOCKED | 泄漏、错位、读未来、预算不符：暂停科学解释，修复原契约；不是算法负结果 |
| 证据 INCONCLUSIVE | 独立组/激活/标注一致性不足：有界补足契约；不因新讨论或日期到期停 A |

A 继续到足以判断是否值得投入；不以“必须得到正面结论”为停止条件。两个注册家族都失败且原因、覆盖、预算充分时，可以建议停止当前方法投入，但须研究者审查，不能把有限候选失败概括为属性学习无效。

一次机制修补必须对应单一原因与预期：例如合法上下文遗漏或区域绑定错误。禁止同时改特征、阈值、反馈预算、数据分区。数据缺口补足也有单独边界；不每遇一个失败就重新申请一套预算。

公开直接竞品时比较其监督、机制、代价和未来评价，不凭标题换题。小而可信的贡献不因低于任意通用百分比被否定；反之，不因投入多、导师提出或概念动听而降低证据要求。

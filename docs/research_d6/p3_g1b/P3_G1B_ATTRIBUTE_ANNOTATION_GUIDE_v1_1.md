# P3-G1B 属性标注判定指南

**版本：Attribute Definition v1.1 — 操作性解释草案**

**目标属性：** `surface_abrasion_visible`

**任务：** 判断当前单张图像的可见物件表面，是否存在具有擦蹭、磨损或浅表划伤形态的局部外观痕迹。

这不是判断产品整体是否正常，也不是诊断损伤的真实物理原因。

### 1. 什么情况属于 Present？

以下情况可以判为 `present`：

- 清楚看到不属于正常纹理的浅表划痕，即使只有一条。
- 清楚看到局部擦蹭或磨花，例如多条细密、不规则的摩擦纹。
- 清楚看到具有擦磨形态的局部表面光泽或涂层变化。
- 即使同时存在污染、凹坑、变形等其他缺陷，只要擦伤本身可见，仍判为 Present。

不要求证明具体摩擦过程，也不要求缺陷达到某种严重程度。关键是**可观察的局部擦划形态**。

### 2. 哪些情况不能直接算 Present？

以下外观不能仅凭出现就判为擦伤：

- **裂纹 Crack：** 不规则开裂、材料分离或断裂纹理。
- **凹坑 Pit：** 局部点状低陷或压痕。
- **污染 Contamination：** 污渍、粉尘、油污、附着物。
- **缺件或破损：** 缺少部件、崩裂、断角。
- **正常纹理：** 规律排列的加工线、注塑接缝、模具痕迹、印刷边界、木材天然纹理。
- **成像现象：** 光照反射、阴影、曝光变化、失焦或压缩伪影。

如果上述缺陷存在，但当前可见表面足以判断不存在擦伤，选择 `absent_assessable`。

如果它们与擦伤在视觉上无法可靠区分，选择 `unobservable_or_uncertain`。

### 3. 四种标注状态

| 状态                          | 实际判定标准                 |
| --------------------------- | ---------------------- |
| `present`                   | 当前视角提供足够证据，支持存在可见擦伤    |
| `absent_assessable`         | 当前视角可以检查相关表面，但没有可信擦伤证据 |
| `unobservable_or_uncertain` | 观察条件不足，或无法可靠区分擦伤与其他外观  |
| `not_applicable`            | 当前图像不存在适用该属性判断的目标表面或对象 |

`not_applicable` 不等于“没有擦伤”，也不等于“图片模糊”。对于正常展示物件表面的 Real-IAD 图像，此选项通常很少需要使用。

### 4. 六种典型易混淆情形

| 观察情况                      | 建议标注                      |
| ------------------------- | ------------------------- |
| 金属表面一条清晰的非设计浅划线           | Present                   |
| 塑料表面出现方向一致的局部磨花纹理         | Present                   |
| 表面只有一个圆形凹坑，没有擦划痕迹         | Absent assessable         |
| 产品明显缺失一个零件，但其他可见表面没有擦伤    | Absent assessable         |
| 图中出现一条细线，但无法区分它是裂缝、接缝还是划伤 | Unobservable or uncertain |
| 高反光或失焦使关键表面无法判断是否擦伤       | Unobservable or uncertain |

如果裂纹、凹坑、污染与真正的擦划痕迹共存，按擦伤是否可见判定，而不是强制选择某一种互斥缺陷类别。

### 5. 每张图像的实际操作

1. 先查看完整图像，理解物件形态及正常结构。
2. 必要时放大至原始分辨率，检查可疑局部。
3. 判断异常是擦划形态、其他缺陷、正常结构还是无法区分的外观。
4. 选择四态之一，记录判断置信度；对于歧义，可在备注里写明 `possible_pit`、`possible_crack`、`possible_contamination`、`normal_texture`、`glare` 或 `blur`。

不能查看其他视角的既有答案、文件名中的缺陷类型、模型预测或数据来源标签来替代当前视角判断。

**核心原则：不确定就是不确定，不强迫二元标注。**

### 6. 多视角与盲重复

同一物件的两个视角可以得到不同属性状态，因为属性可能只在某个视角可见。

盲重复必须独立判断，不得调用第一次呈现时的答案。

备注里的易混淆原因只用于后续人工审核，不自动成为第二套缺陷分类标签。

**本指南必须在正式 G1B 首次标注前冻结。** 如果它与历史 Attribute Definition v1.1 的实际使用存在实质冲突，须先记录分歧，不能在看到新 D-eval 标签后修改定义。

# D6-P2-E1 优化与稳定性分析

**结论：** 合成梯度与实现测试通过；真实初始化兼容性闸门失败，因此没有启动研究优化。

## 解析梯度核验

按注册公式，

`∇w = Xᵀ(sigmoid(Xw+b)-y)/n + λw + γ(w-w0)`  
`∇b = mean(sigmoid(Xw+b)-y)`。

独立合成测试对目标函数做中心差分，并对 Hessian-vector product 做梯度差分；10 项 E1 测试全部通过，包括 gamma=0 目标等价、求解器失败拒绝、预测先于揭示、未知/N-A 不更新、future 标签反事实不改变较早状态、锚点不可变、确定性、分组隔离和输入文件保持。

对保存的真实 D-fit 初始模型，注册目标数值为：

| 量 | 数值 |
|---|---:|
| D-fit 二元样本 | 52（27 正、25 负） |
| λ / γ 检查值 | 1e-4 / 0 |
| Objective | 0.3684378893 |
| 权重梯度无穷范数 | 1.0144558367e-5 |
| 截距梯度 | 1.7226304473e-5 |
| 总梯度无穷范数 | **1.7226304473e-5** |
| 注册成功门槛 | 1e-6 |
| 超过门槛倍数 | 17.23× |

对截距的中心差分为 `1.7226297055e-5`，与解析梯度相差约 `7.4e-12`。这说明失败不是解析梯度实现符号错误造成的。P1-B 的 `C=192.3076923` 与 `alpha=λ=1e-4` 数学映射一致；B0 系数、截距、checkpoint-0 分数及初始状态摘要也全部与归档记录吻合。因此本次证据指向**归档初始化数值未达到新契约的站稳阈值**，而不是输入、分组或模型状态拿错。

## 历史“收敛”字段的含义

P1-B 的 Refit 审计把 `converged=True` 定义为 `n_iter < max_iter`。初始 alpha=1e-4 拟合使用了 108 次迭代，但现存审计没有记录 SciPy 终止消息、梯度范数或 objective 站稳检查。因此该历史布尔值不能证明满足 E1 的 `||∇J||∞≤1e-6`。

未确定残余梯度的精确求解器终止原因。它可能与旧 LogisticRegression 调用允许的函数相对下降停止有关；由于归档结果没有保存终止消息，此解释是推测，不能作为已验证原因。

## 稳定性与状态检查

- P1-B 保存的 B0 与 alpha=1e-4 初始 Refit 参数逐值相同；W/X checkpoint-0 预测最大绝对分差为 `3.55e-15`。
- W/X 初始状态摘要、最终状态摘要和 checkpoint 状态日志可互相核对；15 个原始 P1-B 输出文件均通过既有 SHA-256 清单。
- 源数据和特征快照前后匹配；P1-A、P1-B、R1 与 G0 保护目录未改变。
- 新 Proximal 轨迹、权重漂移、翻转和 solver 稳定性均未发生；Newton-CG 未启动。没有基于 future 指标调参。

停止之后只读计算了已保存 P1-B gamma=0 末状态在相应完整历史数据上的目标/梯度：X 的末状态 gradient infinity norm 为 `5.9341133863e-6`，W 为 `4.9027910871e-7`。因此 X 末状态也未达到本轮 `1e-6` 数值阈值；W 末状态达到该阈值。该诊断没有改写 P1-B，也没有恢复任何历史拟合。X/W 原始 P1-B update 日志提供的二元更新均值耗时分别为 15.96 ms 和 13.89 ms；它们不能当作新 Proximal 的速度。

## 资源记录

因兼容性闸门在任何研究拟合前停止，E1 learner fitting CPU 时间为 0，新增 Proximal 优化数为 0，Newton-CG 数值求解数为 0；30 分钟模型计算预算没有被触及。小型合成测试报告用时约 0.93 秒。阻断分支没有记录完整进程峰值 RSS，故 1 GiB 峰值目标为 **未测量**，不能宣称通过。受控 E1 输出仅包含少量汇总诊断文件，低于 100 MiB 限额。

## 处理决定

不能在本轮中通过放宽梯度门槛、改变 alpha/gamma、从不同参数初始化、重训 gamma=0 或重新拟合 w0 来绕过失败。那会改变已冻结的配对控制。应由研究负责人决定是否单独授权建立一个与注册目标数值兼容的共同 D-fit 起始状态，并为其重新登记匹配的 gamma=0 比较轨迹。

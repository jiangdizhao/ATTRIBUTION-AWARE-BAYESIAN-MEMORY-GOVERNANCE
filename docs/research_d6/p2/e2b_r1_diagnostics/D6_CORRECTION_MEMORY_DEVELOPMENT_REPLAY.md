# D6 开发性纠正记忆回放

## 输入和执行

使用 DINOv2/G-Mean 的 X、W learner 和 B0。每协议 12 次反馈、12 个独立于反馈角色的未来登记组、24 个未来视角；X 的反馈与未来产品互斥，W 在同产品内分组。D-fit 为 54 视角（27P/25A/2U），仅用于原头的既有初始化。X 的反馈为 7P/5A、未来为 12P/9A/3U；W 的反馈为 5P/6A/1U、未来为 14P/7A/3U。按队列首次呈现连接人工标签，未将 U 视为负例。

共同 H 是每个 checkpoint 的已保存 learner 状态，所有纠正锚点由 H 在揭示前的错误建立。每个查询的事件 ID、标签、揭示记录、查询前参数摘要和分数均与归档核对；每协议独立从空记忆开始。H 的各 checkpoint 未来分数重建最大绝对差 `1.07e-14`；两条 B0 的 13 个状态各自不变、初态与 learner 相同。各特征文件和缓存身份通过 D2 验证函数核对。tape SHA-256：`13561809074aad72e2f13289723ccba8addc4768395480c50d3173abf66e8cc1`；DINOv2 特征清单 SHA-256：`3588bab021a9cd8043d663c1d6ce46f366f89f89802fb1ac928dfae3360efddf`；R1 运行身份 SHA-256：`ea1608c59c7070ace67d9db58d24ca19e77fc306569aa57db607ae9ac40bb10a`。逐视角预测和最近锚信息先落盘，随后才连接未来评价标签。

M 是全局单位向量最近锚适配；M+ 使用全局距离与 4×4 有效局部格的双向最近格距离均值，再加查询历史绝对 logit 中位数置信门。两臂用同一纠正记忆和同一头。M+ 的结果是检索与置信门的组合效果。原 H logit 保留，记忆只覆盖二元预测类别。

## 补标判断

当前正负锚均存在，X 放宽门限后已在多个组和产品观察到有益与有害复用；参考点零翻转由距离拒绝解释。W 的 M+ 在当前可复用范围取得 `6 修复 / 0 损害` 的事后点，因此任何后续候选都应先对照该组合基线。现有结果支持制定候选机制及其公平比较，不支持声称 A-1 优越或启动新控制器。

若要补充数据，瓶颈优先是**未来开发组**，而不是只补反馈锚：X 仅有 6 个 H 原错、15 个原对二元视角，且只有 3 个未来产品。可一次预注册新增约 30–60 个未来登记组，跨至少 3 个新增开发产品，并在抽样前固定产品、物件与视角规则；具体数量应受核验预算约束。粗略精度依据：若二元视角独立且最保守比例为 0.5，95% 近似区间半宽 0.25 需要约 16 个原错和 16 个原对评价单位，半宽 0.20 需约 24 个各类单位；当前 X 分母分别为 6 和 15。两视角同组相关、原错比例未知，故 30–60 组只是覆盖与成本规划区间，不保证达到该精度；需按登记组聚合并在新增标签到来后报告实际有效分母。事先按产品和物件取样，不能按候选模型改对/改错选择样本。本次没有发起标注。

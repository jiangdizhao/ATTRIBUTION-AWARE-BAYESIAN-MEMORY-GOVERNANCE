## C. Ranking 损失作用审计

比较同 backbone、protocol、seed 的 M-BCE 与 M-Rank-Softplus。原始随机参数起点在四个 backbone×seed 配对中相同；D-fit 拟合后的初始化参数并不相同。D-fit 拟合时记录的 Ranking 目标分量很小：DINOv2 约 `5.30e-17`，DINOv3 约 `8.43e-11`。因此不得把两者差异归因为“相同已拟合初态后，仅加 Ranking 项”的纯对照。

在 checkpoint 0/12 的未来状态比较中：

- 两 checkpoint 合计各有 8 个配对状态。weight 参数差的均值为 checkpoint 0 `6.04e-4`、checkpoint 12 `3.46e-4`；最大值分别为 `8.40e-4`、`6.43e-4`。bias 差的最大绝对值分别约 `3.54e-5`、`3.18e-5`。
- 未来分数平均绝对差（各状态的 mean-absolute 差再取最大）在 checkpoint 0 为 `2.7e-5`、checkpoint 12 为 `2.2e-5`；最大单分数差分别为 `1.58e-4`、`7.5e-5`。
- 两 checkpoint 各汇总 2,208 个未来样本两两排序比较：排序不一致均为 0；零阈值预测不一致均为 0。即 Ranking 改变了参数和少量分数，但在这些已存未来集合上没有改变阈值预测或任一可比较样本对的顺序。

Ranking 梯度诊断共覆盖 32 个已存状态、每状态 675 个正负 bag 配对（27 个正 bag × 25 个负 bag；合计 21,600 条配对诊断记录）：

- M-Rank-Softplus 的正 Ranking violation 数在 checkpoint 0/12 全部为 0。跨状态最小的 violation 分布 5% 分位仍对应约 `3.784` 的正负 margin；各状态的 median margin 位于约 `6.824–7.589`。这些是分位统计，不声称最小单个 pair margin 等于该值。
- Softplus 导数确实被计算，且所有 M-Rank 状态的导数至少 99% 落在 `≤0.01` 区间（实测为 100%）；跨状态最大导数 95% 分位约 `8.21e-13`，导数中位数约 `1e-27` 量级。这是接近零端的饱和，而非正 violation 区域的饱和。
- M-Rank 加权 Ranking loss 最大约 `1.90e-10`（checkpoint 12），活跃 Ranking 梯度范数最大约 `6.30e-10`。Ranking 梯度与 BCE+L2 梯度范数之比最大约为 checkpoint 0 的 `4.01e-4`、checkpoint 12 的 `2.41e-7`。所以 Ranking 项被纳入计算且梯度非恒为零，但在当前特征/初态与已观察 margin 下几乎没有优化作用。

**机制结论：** 当前 M-Rank 与 M-BCE 的未来预测等价，不是因为 Ranking 代码未执行，而是现有 bag 排序已大幅满足注册 margin，Softplus 导数和相对梯度贡献近零。该结论仅限现有 D-fit 和轨迹，不证明其他 margin、数据或任务下 Ranking 无效；本审计没有调整任何超参数或重拟合。
